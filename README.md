# 🔍 Scanner de Vulnerabilidades em Python

Projeto desenvolvido para análise de portas abertas, identificação de serviços e detecção básica de possíveis riscos de segurança.

## 🚀 Funcionalidades

- Scan de portas TCP
- Identificação de portas abertas, fechadas e filtradas
- Banner grabbing (identificação de serviços)
- Suporte a HTTP e HTTPS
- Multithreading para melhor performance
- Detecção de possíveis vulnerabilidades (FTP, Telnet, SMTP)
- Geração de relatório automático

## 🧠 Tecnologias utilizadas

- Python
- Socket
- Threading
